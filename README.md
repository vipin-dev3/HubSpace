# HubSpace — Curated Digital Atlas & Bookmark Directory 🚀

**HubSpace** is a high-performance, precision-crafted bookmark directory and digital intelligence atlas built with **React 19**, **Vite**, and **Tailwind CSS**. It organizes, searches, and accesses categorized web resources with zero latency, client-side persistence, single-user authenticated vault access, and one-click data backup.

---

## ✨ Features

- **🔐 Private Vault Authentication**: Secure single-user client gate with persistent sessions.
- **🎨 7 Aesthetic Appearance Themes**:
  - **Obsidian**: Architectural blueprint with cobalt blue precision
  - **Dracula**: Vampiric gothic twilight with neon purple & pink accents
  - **Matrix Cyber**: Deep black terminal with phosphor emerald glow
  - **Tokyo Night**: Neon twilight navy with synthwave cyan
  - **Nord Frost**: Arctic Scandinavian slate with glacial cyan
  - **Amber CRT**: Vintage monochrome CRT terminal with warm gold
  - **Clean Studio**: High-contrast paper canvas with international blue
- **🏛️ Bespoke Architectural Design**: Eliminates generic AI template patterns in favor of a precision software design language (fine technical dot-matrix grid, controlled ambient light, and hairline borders).
- **⚡ Hybrid Command Search (Fuse.js)**: Instant fuzzy and substring search across bookmark titles, URLs, descriptions, tags, and category names with real-time match counters.
- **🗂️ 13 Curated Knowledge Clusters (67 Tools)**:
  - AI Tools (Benchmark arenas, model hubs, generative UI)
  - Movies And TV Shows / Anime
  - Education / Courses / Coding / Essay
  - Books & Digital Libraries
  - Presentation / PDF
  - Softwares / Tools
  - Download / Deleted / Transfer
  - Edit / Logo / Animation / QR
  - Cyber / Security
  - Games
  - GitHub (OSINT & Developer Repos)
  - Lists & Indexes
  - Typing Mastery
- **🧭 Rapid Category Switcher & Pill Rail**:
  - Executive category dropdown with item counters.
  - Horizontal 1-click Category Pill Rail for rapid filtering.
- **👁️ 3 Versatile View Modes**:
  - **Detailed Cards**: Precision hairline cards with descriptions, monogram favicons, clean domain pills, and animated `ArrowUpRight` launch buttons.
  - **Compact Grid**: High-density view for rapid scanning.
  - **List View**: Dense tabular data rows with direct links and visit telemetry.
- **📊 Executive Telemetry Deck**: Real-time status ribbon tracking Total Nodes, Knowledge Clusters, Launches Telemetry, and Vault Sync status.
- **💾 Persistent Browser Storage**: All custom additions, edits, and launch counts persist permanently across page refreshes via `localStorage`.
- **📦 Data Backup & Restore**: Export bookmarks to `.json` and import/merge external link collections anytime.
- **⌨️ Keyboard Shortcuts**:
  - `/` or `Ctrl + K`: Focus search bar instantly
  - `Escape`: Clear search and close active filters

## 🚀 Getting Started Locally

### Prerequisites
- Node.js `v18+` or `v20+`
- npm or pnpm or yarn

### 1. Clone & Install
```bash
git clone https://github.com/vipin-dev3/HubSpace.git
cd HubSpace
npm install
```

### 2. Start Development Server
```bash
npm run dev
```
Open your browser at `http://localhost:5173` and enter your configured credentials to access the directory.

### 3. Build for Production
```bash
npm run build
```
